## GEO-Inquire FAIR Assessments

This project contains an archived version of the software developed within WP7 of Geo-INQUIRE to manage FAIR assessments. This software is written in PHP using the Laravel framework. 
It requires a MySQL database for data storage and needs a configured instance of a FUJI server to perform FAIR analysis.
